# MSL LAB 4 - Express Web Application

A modern Node.js & Express web application that dynamically fetches and renders REST API data using Vanilla JavaScript.

## 📌 Project Overview
- **Student Name**: Rijbi-Khan
- **Repository**: https://github.com/Rijbi-Khan/Rijbi-Khan-msl-lab-4
- **Tech Stack**: Node.js, Express.js, HTML5, CSS3 (CSS Variables & Flexbox/Grid), Vanilla JavaScript (Async/Await)

## 🚀 How to Run Locally

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start the Express Server**:
   ```bash
   npm start
   ```

3. **Open in Browser**:
   Navigate to `http://localhost:5000`
